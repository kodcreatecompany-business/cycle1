# VESCO Downtown scroll site (Next.js)

Run locally: `npm install` then `npm run dev` and open http://localhost:3000

Deploy on Vercel: push this folder to GitHub and import it at vercel.com/new (no settings needed), or run `npx vercel` in this folder.

Edit text in `lib/parts.js`. Check the copy against your real spec sheet (frame material, gears, tyre size).
Part cut-outs are defined in `lib/shapes.json` (pixel coordinates on public/bike.png).
